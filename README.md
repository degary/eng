# 🏠 英语启蒙小屋

一个纯静态的英语启蒙网站，适合 2-3 岁儿童。开箱即用，可直接部署在 1Panel 等静态网站环境。

## 功能

- 📅 **每日计划** — 按日期自动轮播推荐的场景、儿歌、词汇、动物
- 💬 **亲子场景英语** — 13 个日常生活高频场景（起床、吃饭、洗澡、穿衣、外出、睡前等）
- 🦁 **动物园专题** — 动物园动物 + 路上常见小动物，含拟声词和例句
- 🎵 **儿歌** — 19 首经典英文儿歌，逐句歌词 + 中文翻译
- 🃏 **词汇闪卡** — 9 个分类，约 100 个高频词
- 📋 **发展测评** — 按月龄对照的英语接受能力自评表
- 📈 **打卡记录** — 连续打卡天数、历史记录、热力图

所有数据保存在浏览器 `localStorage` 中，无需后端、无需数据库。

## 项目结构

```
eng/
├── index.html              # 页面入口
├── css/
│   └── style.css           # 全部样式
├── js/
│   ├── state.js             # 本地存储、宝宝档案、打卡统计
│   ├── audio.js             # 音频播放（本地 mp3 优先，自动回退浏览器 TTS）
│   └── app.js               # 页面渲染与交互逻辑
├── data/
│   └── content.json        # 全部内容数据（场景/儿歌/词汇/动物园/测评）
├── audio/                    # 本地音频文件存放目录（见下方生成说明）
│   └── manifest.json        # 文本 -> 音频文件名映射，由生成脚本自动产出
└── scripts/
    └── generate_audio.py    # 本地批量生成音频的脚本
```

## 本地预览

无需安装任何依赖，用任意静态文件服务器打开即可（不能直接双击 index.html，因为用到了 `fetch` 加载 JSON，浏览器本地文件协议会被拦截）：

```bash
cd eng
python3 -m http.server 8000
# 然后浏览器打开 http://127.0.0.1:8000
```

如果暂时没有生成本地音频文件，点击喇叭图标会自动使用浏览器内置的 Web Speech API 朗读（效果稍弱于真人语音，但不影响正常使用）。

## 音频生成（推荐，发音更自然）

服务器所在网络环境通常无法访问 Google TTS，因此采用 **Edge TTS**（微软必应连接的免费 TTS 服务，国内网络一般可直连）在本地生成好音频文件，再整体上传到服务器。

### 步骤

1. 在你自己的电脑上（有正常网络访问）安装依赖：

   ```bash
   pip install edge-tts
   ```

2. 运行生成脚本（在项目根目录下）：

   ```bash
   python3 scripts/generate_audio.py
   ```

   脚本会：
   - 读取 `data/content.json` 里的所有英文句子/单词（场景对话、儿歌歌词、词汇、动物园句子）
   - 逐条调用 Edge TTS 生成 mp3，保存到 `audio/` 目录
   - 生成 `audio/manifest.json`，记录「文本 → 音频文件名」的映射

3. 生成完成后，`audio/` 目录大概包含 300-400 个 mp3 文件（每个文件几十 KB，总体积约 10-20MB，具体取决于文本长度）。

4. 把整个 `audio/` 文件夹（包含 `manifest.json` 和所有 `.mp3`）上传到服务器项目目录下，与 `index.html` 同级。

### 常用参数

```bash
# 指定其他语音角色（默认 en-US-AnaNeural，儿童友好女声）
python3 scripts/generate_audio.py --voice en-US-JennyNeural

# 提高并发数加快生成速度（注意不要设太高，避免被限流）
python3 scripts/generate_audio.py --concurrency 8

# 内容更新后，强制重新生成全部音频（默认只增量生成新增文本）
python3 scripts/generate_audio.py --force
```

### 内容更新后如何同步音频

如果以后修改了 `data/content.json`（新增场景、儿歌或词汇），只需重新运行一次生成脚本即可：脚本会自动跳过已经生成过的文本，只为新增内容生成音频，然后把新增的 mp3 和更新后的 `manifest.json` 一起上传覆盖即可。

## 部署到 1Panel

1. 在 1Panel 中创建一个静态网站（或 Nginx 站点）。
2. 将整个 `eng/` 项目目录（`index.html`、`css/`、`js/`、`data/`、`audio/`）上传到网站根目录。
3. 确认网站根目录直接能访问到 `index.html`（无需任何服务端渲染或接口）。
4. 访问网站域名即可使用。

> 本项目纯前端静态文件，不依赖 Node.js、PHP 等运行环境，只需任意能托管静态文件的 Web 服务器（Nginx / Apache / 1Panel 内置静态站点）即可。

## 后续扩展

当前内容面向 2-3 岁儿童设计（场景简单、句子短、重复度高）。如需支持更大年龄段儿童（如学龄前、小学低年级），可以：
- 在 `data/content.json` 中增加新的场景/词汇分类
- 调整 `js/app.js` 中的渲染逻辑以支持更复杂的内容形式（如简单问答、拼读练习等）
- 重新运行 `scripts/generate_audio.py` 生成新增内容的音频

欢迎随时提出新需求。
